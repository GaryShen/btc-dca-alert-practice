# btc-dca-alert｜BTC 定投提醒

用 AI 從零做出來的 BTC 定投提醒工具。規則你自己定、指標你自己選，它每天幫你檢查，條件到了就推播到手機。

**只提醒，不下單。** 不碰你的交易所帳號，只讀公開資料。

> 這是 YouTube 頻道「AI 萬事屋」六週連載〈六週，用 AI 做出第一個小工具〉的範例 repo。
> 頻道：https://www.youtube.com/@ai_yorozuya ｜ 系列播放清單：https://www.youtube.com/playlist?list=PLQXjWr_G6FAY

## 目前進度

**W3 價格從哪來？指標能加嗎？（`v0.3`）**：打開網頁會自動抓 Kraken 的最新價格，接在內建資料（到 2026-09-28）後面；抓不到就在畫面上明講、改用內建資料。加碼條件改成指標插件，選單有「距最高點跌幅」和「恐懼貪婪指數」（資料來源 alternative.me）。想自己加指標：照 [`indicators/drawdown.js`](indicators/drawdown.js) 的格式在 `indicators/` 新增一個檔案，再到 [`indicators/清單.js`](indicators/清單.js) 登記一行。指令在 [`prompts/W3.md`](prompts/W3.md)，價格來源比較和怎麼換在 [`docs/免費API清單.md`](docs/免費API清單.md)，作業答案在 [`docs/W3_標準答案.md`](docs/W3_標準答案.md)，準備步驟在 [開工檢查〈W3〉](docs/開工檢查.md)。

**W2 改壞了怎麼辦？（`v0.2`）**：程式和 W1 一樣，多了一張安全網：用 Git 存檔、改壞了一步退回，加上給 AI 的工作守則 [`CLAUDE.md`](CLAUDE.md)。指令在 [`prompts/W2.md`](prompts/W2.md)，救援指令在 [`docs/Git救援小抄.md`](docs/Git救援小抄.md)，準備步驟在 [開工檢查〈W2〉](docs/開工檢查.md)。

**W1 第一版（`v0.1`）**：本機網頁 [`index.html`](index.html)，下載後雙擊就能打開（不用網路、不用裝東西）。填開始／結束日期、每週金額、跌幅門檻、加碼倍數，按「計算」就會用 2017-01-02～2026-09-28 的每週價格算出兩條規則的結果；網址最後加 `#test-w1` 是驗收模式。規則寫在 [`docs/需求單.md`](docs/需求單.md)。

**想從頭跟著做**：到 **Tags** 下載 `v0.0`（價格資料和跟做文件，還沒有網頁），照 [`docs/開工檢查.md`](docs/開工檢查.md) 開始；指令在 [`prompts/W1.md`](prompts/W1.md)，標準答案在 [`docs/W1_標準答案.md`](docs/W1_標準答案.md)。**從 W2 開始**：下載 `v0.1`。**從 W3 開始**：下載 `v0.2`（ZIP 裡沒有存檔紀錄，先貼 W2 指令包第 1 節「開始存檔」）。

之後每週的成果打一個版本標籤（`v0.1` … `v0.6`）。

## 做完會長這樣（示意）

範例規則：每週一投 100 美元；距離「資料中最高」跌超過 30%，改投 2 倍。

```text
定投提醒｜週一 09:00（示意）
條件符合
依你設定的規則：本週投入 $200
BTC $84,444・距資料中最高 $123,519 跌 31.6%・門檻 30%
```

數字是用 2026-09-28 那週的價格算的示意。「資料中最高」是每週一取樣的最高價，不是盤中歷史最高；規則只是範例，不代表這條規則比較好。

## 六週路線圖

| 週 | 這週回答的問題 | 做完之後，工具能做什麼 | 版本 |
|---|---|---|---|
| W1 | 第一版怎麼做出來？ | 本機網頁：設規則，用過去的價格算出結果 | `v0.1` |
| W2 | 改壞了怎麼辦？ | 有版本紀錄，AI 改壞了也能一步退回 | `v0.2` |
| W3 | 價格從哪來？指標能加嗎？ | 價格和指標自動抓；指標可以選，也可以自己加 | `v0.3` |
| W4 | 資料存哪？誰看得到？ | 規則和結果存到雲端，登入後只有你看得到 | `v0.4` |
| W5 | 電腦關了，誰幫我看？ | 放上網路，每天自動檢查，條件到了推播到手機 | `v0.5` |
| W6 | 它算的，對嗎？ | 自動測試對答案，確認它算的是對的 | `v0.6` |

W1 先讓 AI 做出第一版；W2 到 W6 跟 AI 一起把它改到真的能用。做完這六週，換成你自己的題目，這些做法也用得到。

## 每週你會拿到

- **指令包** `prompts/W{n}.md`：影片裡下給 AI 的指令，可以直接複製。
- **版本標籤** `v0.0` 是 W1 的起點（還沒有網頁）；`v0.1` … `v0.6` 是每週的成果。卡關時切到那一週的標籤對照；中途加入的人，從那一週的標籤接著做。
- **工程師驗收**：每集最後的驗收清單（完成／驗證／範圍／下一步）。

### 沒寫過程式，怎麼拿到這些檔案？

按右上角綠色的 **Code** → **Download ZIP**；想要某一週的版本，到 **Tags** 挑那一週下載。W2 會教怎麼用 Git 存檔、用 GitHub Desktop 放上 GitHub。

## 要準備什麼

- 一台電腦（Mac、Windows 都可以）
- Claude 付費方案：Pro 以上（含 Claude Code）。有使用額度，用到上限要等一下。（2026 年 10 月查證，方案內容可能變動）
- 其他服務都用免費方案，用到那週再一起註冊：
  - GitHub（W2）
  - Supabase（W4）
  - Vercel（W5，免費方案限非商業用途）
  - 推播服務（W5，暫定 Telegram）

## 這個工具不做的事

- 不下單、不自動交易
- 不連你的交易所帳號
- 不給投資建議：推播只代表你自己設的條件到了

模擬的是過去的價格，不代表未來，也不是投資建議。

## 資料來源
