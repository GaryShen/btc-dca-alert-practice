# 價格資料

`btc_weekly.csv`：BTC 每週價格，2017-01-02 ～ 2026-09-28，共 509 週。

| 欄位 | 說明 |
|---|---|
| `date` | 日期（每週一，YYYY-MM-DD） |
| `price_usd` | 當天的市場均價，美元，四捨五入到整數 |

- 來源：blockchain.com 的每日市場均價（Market Price, USD），https://www.blockchain.com/explorer/charts/market-price
- 取樣：每週一一筆
- 擷取：2026-10-01

W1、W2 只用這份固定的檔案。W3 起，網頁打開時會從 Kraken 抓 2026-09-28 之後的週價格，接在這份資料後面；這份檔案不改，留著當離線備用（抓不到時照樣能算）。

W1 製作時由 Claude Code 讀取**完整 CSV**，把資料內嵌進 `index.html`，讓成品可直接雙擊、離線使用；本檔保留為來源。若修改 CSV，需要重新內嵌並驗收，已產生的 HTML 不會自動跟著變。

開始與結束日期只限制買入區間，不能先截掉開始日期之前的價格，因為計算「截至當週的最高點」仍需要更早的資料。合成驗收資料只傳給同一個計算函式，不覆蓋本檔。

「資料中最高」指的是這份資料裡、截至當週的最高價，不是盤中的歷史最高價（資料是每週一取一次的日均價，而且從 2017 年開始）。
