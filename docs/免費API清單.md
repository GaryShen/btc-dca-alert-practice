# 免費 API 清單（W3）

這集網頁打開時，會自己去抓新的週價格，接在內建資料（`data/btc_weekly.csv`，到 2026-09-28）後面。
下面是我們比較過的幾個免費來源。挑來源先看兩件事：**不用金鑰**、**雙擊打開的網頁抓得到**。

> 「雙擊打開的網頁抓得到」是 2026-10-21 在 Chrome 實測的結果。網址開頭是 `file://`，
> 有些網站會被瀏覽器的跨網域限制（CORS）擋下來：伺服器那邊有回應，但瀏覽器不讓網頁拿到。

連結與說法 2026-10-23 重新查過；API 規則會變，用之前再看一次官方文件。

### Kraken 要注意的兩件事（官方文件）

1. **最多只給最近 720 筆**：每日 K 線大約兩年。內建 CSV 到 2026-09-28，兩年內接得起來；CSV 太久沒更新，中間會缺週。
2. **最後一筆是還沒結束的時段**：週一當天打開網頁，這週一的成交均價還會變，所以最後一筆如果是今天，就先不要拿來當週一價格，等收盤後再用。

## 想換價格來源

照自己喜歡、相信的來源換就好。打開 `prompts/W3.md` 第 1 節，只改兩個地方：

1. **網址**：換成那個來源的價格 API 網址。
2. **要取哪個值**：寫清楚取哪一欄（例如「收盤價」或「當天均價」），還有怎麼對到每週一。

其他句子（接在 2026-09-28 後面、抓不到要在畫面上明講、CSV 不要改）照舊。改完一樣先看 AI 改的需求單，再驗收：
舊案例（`#test-w1`）要維持 12 / 12；新的週價格，先拿同一天其他網站的最高、最低做**合理性檢查**（落在中間＝價格合理）。但收盤價、相鄰日期的價格也可能落在同一個區間，所以日期和取的是哪一欄，要再對一次那個來源的原始資料（例：Kraken 10/19 的成交均價 82,279.5，取整數就是網頁上的 $82,280）。

不同來源的價格本來就會差一點（算法、成交所不同），9/28 前後不是同一個數字來源。
