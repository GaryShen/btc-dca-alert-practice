# 開工檢查：W1 從零跟做或看完成版

這個系列用 **Claude 桌面 App 的 Code 分頁** 寫程式。使用這個分頁不用另外裝 Node.js 或 CLI；本集指令也要求成品不依賴外部套件，雙擊就能開。

## 1. 準備

- 一台電腦：Mac 或 Windows。
- Claude 付費方案：本集以 Pro 以上示範。[官方方案](https://claude.com/pricing)
- 確認帳號可使用 Claude Design：本集在 Code 分頁打 `/design` 叫出它（桌面 App 要更新到最新版）。若無法使用，但 Code 可用且仍有額度，可直接請 Code 依需求單製作。
- Design 與 Code 共用用量額度；開始前先看剩餘額度。若共用額度已用完，等重設再繼續。[官方 Design 說明](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

## 2. 安裝與登入

1. 到 [Claude Code 桌面版官方快速入門](https://code.claude.com/docs/en/desktop-quickstart) 下載並安裝 Claude 桌面 App。
2. 開啟 App，以你的 Claude 帳號登入。
3. 點畫面上方的 **Code** 分頁。若提示升級，確認帳號方案；若要求網頁登入，完成後重新開啟 App。

## 3. 從零跟做：下載起點 `v0.0`

1. 到範例 repo 的 **Tags**，找 `v0.0`，下載 ZIP 解壓縮。`v0.0` 是這週的起點，裡面是價格資料和跟做文件（標準答案、指令包、這份開工檢查），**還沒有網頁**。
2. 把解壓縮出來的資料夾改名成 `btc-dca-alert-practice`（名字隨你），放在好找的地方。裡面應該長這樣：

```text
btc-dca-alert-practice/
├── README.md
├── data/
│   ├── btc_weekly.csv
│   └── README.md
├── docs/
│   ├── W1_標準答案.md
│   └── 開工檢查.md
└── prompts/
    └── W1.md
```

3. 回 Code 分頁，選 **Local → Select folder**，選這個資料夾。
4. 輸入：

```text
請確認 data/btc_weekly.csv 和 docs/W1_標準答案.md 都存在。
讀取 CSV 的欄位、第一筆日期、最後一筆日期和資料筆數給我看，不要修改檔案。
```

應看到欄位 `date, price_usd`，日期 2017-01-02～2026-09-28，共 509 筆（不含標題列）。這代表 Code 讀得到資料，還不代表網頁做好了。

5. 打開 [W1 指令包](../prompts/W1.md)，照第 1 步請 Code 建立 `docs/需求單.md`，再交給 Design，最後交回 Code。

這一週用不到 Git，下載 ZIP 就好；W2 才教。找不到 `v0.0`，代表這週的起點還沒放上去。

## 4. 只想看完成版

下載並解壓縮 `v0.1`，在該資料夾直接雙擊 `index.html`；不必另建練習資料夾。用 [標準答案](W1_標準答案.md) 設定 A、B、C 核對結果。

完成版已內嵌固定價格，所以不需手動匯入 CSV。若之後修改來源 CSV，成品內嵌資料不會自動更新，必須請 Code 重新內嵌並驗收；W3 才改自動抓資料。

## 5. 驗收成功的畫面

- 正式畫面有五個輸入：開始日期、結束日期、每週金額、跌幅門檻、加碼倍數。
- A 設 2026-01-19～2026-02-09，每週 100、門檻 30%、2 倍：加碼規則的四週投入 100、100、200、200，總投入 $600。
- 網址末尾加 `#test-w1`，同頁驗收模式標示「合成資料」，B 總投入 $500，剛好跌 30% 的那週不加碼。
- 返回正式畫面，重跑 A 仍是 $600；離線也能計算。

## 卡住了？

- **Code 看不到檔案**：確認選的是練習資料夾，CSV 在它下面的 `data/`，不是另一層重複資料夾裡。
- **雙擊後沒有價格／要求啟動服務**：把畫面告訴 Code，請它依需求單改成完整資料內嵌、無外部依賴的單頁 HTML，不以啟動伺服器代替這次的交付要求。
- **A 算到九月才停**：確認結束日期設為 2026-02-09，網頁顯示 4 週。
- **B 得到 $600**：照指令包第 4 步最後那段，把第 3 週的預期和實際告訴 Code，請它先說明哪裡判斷錯，再修正正式畫面用的計算，重跑 B 和 A。
- [官方疑難排解](https://code.claude.com/docs/en/desktop#troubleshooting)。
- 需要留言求助時，附上卡在哪一步與錯誤訊息；截圖遮住帳號與個人資料。

整理與查證：2026-10-07；介面文字以實際畫面為準。本文件描述驗收標準，不代表你的成品已驗收通過。

## W2｜改壞了怎麼辦？

這週會用到 **Git**（電腦上的存檔工具）、**GitHub**（放存檔的雲端倉庫）和 **GitHub Desktop**（不用打指令就能上傳）。全部免費。

### 1. 練習資料夾

- 跟著 W1 做的人：用你 W1 的練習資料夾就好。
- 沒跟到 W1：到 **Tags** 下載 `v0.1` 的 ZIP、解壓，改名 `btc-dca-alert-practice`。雙擊 `index.html`、網址加 `#test-w1`，看到「全部相符」再開始。

### 2. GitHub 帳號

1. 到 [github.com](https://github.com) 註冊（免費方案就夠）。
2. 建議先到 **Settings → Emails**，勾 **Keep my email addresses private**。之後的存檔會帶著 email，推上 GitHub 後別人看得到；開了這個就會用 `…@users.noreply.github.com` 代替。

### 3. GitHub Desktop

1. 到 [desktop.github.com](https://desktop.github.com) 下載安裝。
2. 打開後選 **Sign in to GitHub.com**，會跳到瀏覽器授權。
3. **Configure Git**：Name 填你想顯示的名字；Email 選 `…@users.noreply.github.com` 那個。這一步會設定電腦上 Git 的存檔署名，Claude Code 存檔時也用這組。

### 4. 電腦上的 Git

- **Mac**：打開「終端機」，輸入 `git --version`。出現版本號就好；如果跳出要安裝「命令列開發者工具」的視窗，按 **安裝**，裝完再試一次。
- **Windows**：安裝 [Git for Windows](https://git-scm.com/downloads/win)，裝完重開 Claude 桌面 App。

### 5. 回到 Code 分頁

**Local → Select folder** 選練習資料夾。資料夾變成 Git 專案之後，開新 session 時分支名稱旁會有 **worktree** 選項：**這系列不要勾**（勾了會在另一個資料夾改，你雙擊原本的 `index.html` 看不到修改）。

指令在 [W2 指令包](../prompts/W2.md)，救援指令在 [Git 救援小抄](Git救援小抄.md)。

### W2 卡住了？

- **Code 說找不到 Git（`git: command not found` 之類）**：電腦上還沒有 Git。Mac 會跳出「安裝命令列開發者工具」的視窗，按 **安裝**，裝完叫 Code 重試；沒有跳視窗就照上面第 4 步，在終端機打 `git --version`。Windows 照第 4 步裝 Git for Windows，裝完**重開 Claude 桌面 App** 再試。注意：裝了 GitHub Desktop 不等於有 Git——Desktop 用的是它自己內建的那份，Code 用不到。
- **Code 說 Git 沒設定名字或 email**：回 GitHub Desktop 的 **Settings → Git** 填好，再請 Code 重試。不要讓它自己亂填。
- **改壞後驗收頁還是全部相符**：看第 3 週的「預期」是不是被改成 200——它連考卷答案一起改了。照指令包第 5 步退回。
- **退回後網頁沒變**：瀏覽器要重新整理；確認你雙擊的是練習資料夾裡的 `index.html`，不是 worktree 裡的。
- **Publish 說名稱已存在**：GitHub 上已經有同名 repo，換一個名字。
- **Push 失敗**：先在 GitHub Desktop 確認登入的是同一個帳號。

整理與查證：2026-10-11；App 介面文字以實際畫面為準。

## W3｜價格從哪來？指標能加嗎？

這週不用註冊新服務：價格（Kraken）和恐懼貪婪指數（alternative.me）都是免費、不用金鑰的公開 API。

### 1. 練習資料夾

- 跟著 W2 做的人：用你 W2 的練習資料夾就好。
- 沒跟到 W2：到 **Tags** 下載 `v0.2` 的 ZIP、解壓，改名 `btc-dca-alert-practice`。ZIP 裡沒有存檔紀錄，開工先貼 [W2 指令包](../prompts/W2.md)第 1 節「開始存檔」。

### 2. 用瀏覽器打開

- 網頁打開時才去抓新價格，要有網路。用 Chrome、Safari 這類瀏覽器雙擊 `index.html`；Claude Code 裡的預覽視窗抓不到最新價格。
- 抓到了，畫面上方會寫「價格資料到 …」；抓不到，會寫「抓不到最新價格，改用內建資料（到 2026-09-28）」，照樣能算。

### 3. 回到 Code 分頁

**Local → Select folder** 選練習資料夾，開新 session（worktree 一樣不要勾）。指令在 [W3 指令包](../prompts/W3.md)，價格來源比較在 [免費 API 清單](免費API清單.md)。

### W3 卡住了？

- **一直寫「抓不到最新價格」**：先確認有網路；公司或學校的網路可能擋外部網站，換個網路試試。在 Code 的預覽視窗裡打開也會抓不到，改用瀏覽器雙擊。
- **指標標「準備中」**：正在抓資料，等幾秒；10 秒沒回應會改標「出錯」。驗收模式（`#test-w1`）不上網，不會去抓。
- **指標標「出錯」**：畫面上會寫出是哪個指標（哪個檔案）出了什麼錯，其他指標照常能用。把那段錯誤訊息貼給 Code。
- **新加的指標沒出現在選單**：確認 `indicators/清單.js` 有登記那一行，檔名一字不差。

整理與查證：2026-10-24；API 規則和 App 介面會變，以實際畫面為準。
